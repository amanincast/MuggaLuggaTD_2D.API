Testing is by invitation. If you have been sent an invite code, download the launcher below: it installs the game, keeps it up to date, and starts it.

DOWNLOAD FOR WINDOWS

WINDOWS 10 OR 11 · 64-BIT

INSTALLING

  1. Run MuggaLuggaSetup.exe. Nothing asks for an administrator: it installs for you only.
  2. Windows may say “Windows protected your PC”. The tester build is not signed yet, so click More info, then Run anyway. Your browser may also ask you to Keep the download.
  3. The launcher opens and downloads the game (about 80 MB the first time). When it says Ready to play, press PLAY.
  4. In the game, choose Forge New Herald and enter a name, your invite code, your email and a password (the game calls it your sigil). Each code is good for one account.

AFTER THAT

Start the game from the MuggaLugga shortcut on your desktop or Start menu. It opens the launcher, which fetches any update before you play: only the files that changed.

If the game will not start, press Repair in the launcher. To remove it, use Settings › Apps › Installed apps › MuggaLugga › Uninstall. Your account and progress live on the server and are not lost.

LATEST VERSION

Something wrong? Press Open log in the launcher and send that file with a note of what happened.
